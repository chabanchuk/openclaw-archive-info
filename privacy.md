# Privacy Policy

Last updated: 27 October 2026

## Purpose and operator

OpenClaw Archive rclone is a personal backup utility operated by Serhii Chabanchuk. It is used to transfer encrypted backup archives to the operator’s own Google Drive.

## Google user data

The utility requests the `drive.file` permission. This permits access to files created by or explicitly opened with the application, rather than unrestricted access to all Google Drive files.

It processes backup file contents, file names, identifiers, sizes, checksums and other metadata needed to transfer and verify backups. It may also query available storage quota.

The utility is not designed to access Gmail, contacts or calendars.

## Use and sharing

Google user data is used only to operate and verify the owner’s backups. It is not sold, used for advertising or used to train AI models.

Backup archives and associated metadata are processed on the operator’s devices and server and stored in the operator’s Google Drive. Google processes data under its own applicable terms and privacy policy.

## Credentials and security

OAuth credentials are stored in access-restricted configuration files on the operator’s systems. They are not published on this website or in its public source repository.

Backup archives intended for off-site storage are encrypted before upload.

## Retention and deletion

Backups remain until the operator deletes them according to their backup retention needs. Local operational records may remain for troubleshooting and verification.

The operator can revoke the application’s access through Google Account settings and delete its credentials from local systems. Revoking access does not automatically delete existing backups; these must be deleted separately from Google Drive and any local copies.

## This website

This website provides public application information. It does not request Google authorization, receive backup archives or use application-added analytics or tracking scripts. GitHub Pages may process technical request information under GitHub’s privacy policy.
