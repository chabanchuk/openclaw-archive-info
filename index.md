# OpenClaw Archive rclone

OpenClaw Archive rclone is a private backup utility operated by Serhii Chabanchuk for personal use. It uses rclone to transfer encrypted backup archives to the operator’s own Google Drive.

## Google Drive access

The utility requests the `drive.file` permission to create and manage files created by or explicitly opened with this application. It does not request unrestricted access to all files in Google Drive.

Google authorization is used by the backup utility. This public information website does not provide Google sign-in or receive OAuth credentials.
